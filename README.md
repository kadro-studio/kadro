# Kadro

**Kadro** (эсперанто: «кадр») — бесплатный видеоредактор с открытым исходным кодом. По возможностям он ориентируется на Movavi Video, Filmora, CapCut и Adobe Premiere Pro, но написан с нуля, без заимствования их кода.

Без лицензий, водяных знаков, подписок и учётных записей. Проект живёт на добровольной поддержке.

**[kadro.studio](https://kadro.studio)** · **[Скачать для Windows](https://github.com/kadro-studio/kadro/releases/latest)**

Electron + React + TypeScript, собственный WebGL2-композитор, FFmpeg для декодирования и кодирования, ИИ-модели, которые работают прямо на компьютере.

## Возможности

**Монтаж**
- Многодорожечный таймлайн: добавление, удаление и переименование дорожек; скрыть, выключить звук, соло, заблокировать; высота дорожек меняется перетаскиванием
- Инструменты как в профессиональных редакторах: выделение, выделение вперёд, ripple-, roll-, slip- и slide-правка, лезвие
- Привязка к краям клипов, курсору и маркерам; ripple-удаление и удаление пробелов
- Копировать, вырезать, вставить, дублировать, вставить атрибуты (цвет, эффекты, маска, анимация…); отмена и повтор
- Маркеры с названиями и цветами (перетаскиваются по линейке), точки входа и выхода (I/O) с экспортом только выделенного диапазона, повтор воспроизведения (всего проекта или диапазона I/O)
- Лезвие с Shift режет все дорожки сразу; разрезать все дорожки можно и одной командой
- Нарезка клипа по сменам сцен, метки в ритм музыки (определение темпа), импорт субтитров .srt / .vtt
- Скорость клипа 0.1×–16× без изменения высоты тона, стоп-кадр, обратное воспроизведение, отделение звука

**Изображение**
- Трансформация, обрезка и поворот прямо мышью в окне просмотра; ключевые кадры с плавными кривыми
- Цветокоррекция, цветовые круги lift / gamma / gain, RGB-кривые, выборочный цвет HSL (8 диапазонов), импорт 3D LUT (`.cube`), 15 фильтров-«лутов»
- Свои фильтры: цвет, кривые, LUT и эффекты клипа сохраняются одним пресетом и применяются к любым клипам
- Корректирующие слои, 18 режимов наложения (перекрытие, мягкий свет, осветление/затемнение основы, цветность, яркость…), хромакей, маски
- 20 шейдерных эффектов и 12 шейдерных переходов плюс 22 классических перехода, анимации появления и исчезновения
- Компоновки в один клик: картинка в картинке, разделённый экран, три колонки, сетка 2×2
- Стабилизация дрожащего видео (vid.stab, два прохода)
- Видеоскопы: осциллограф яркости, RGB-гистограмма, вектороскоп

**Текст и элементы**
- 22 стиля титров и 24 встроенных шрифта с кириллицей (OFL), градиентная заливка, толщина начертания, ВЕРХНИЙ регистр, обводка, тень, подложка; системные шрифты тоже доступны
- Свои шрифты (TTF, OTF, WOFF): кнопка «+» в выборе шрифта или просто перетащить файл в окно; свои стили титров сохраняются вместе с анимацией и положением
- 17 анимированных элементов, нарисованных шейдерами: засветки, плёночное зерно, боке, снег, дождь, конфетти, блёстки, туман, блики, VHS, старая плёнка, светлячки, рамка и фоны (звёзды, северное сияние, градиент, синтвейв)
- 14 фигур, эмодзи-стикеры, цветные плашки

**Звук**
- Громкость до 400 % с ключевыми кадрами, нарастание и затухание, трёхполосный эквалайзер, компрессор
- Шумоподавление и нормализация громкости по EBU R128 (−14 / −16 / −23 LUFS), автоприглушение музыки под голос
- Запись закадрового голоса с микрофона во время воспроизведения; индикатор уровня L/R

**ИИ (локально, без облака)**
- Автосубтитры (Whisper) с экспортом в `.srt`
- Удаление фона у видео и изображений (MODNet) с прозрачностью

**Онлайн-библиотека**
- Бесплатные видео (Wikimedia Commons), фото, музыка и звуковые эффекты (Openverse) без регистрации; Pexels и Pixabay — с бесплатным личным ключом API
- Только свободные лицензии (CC0, общественное достояние, CC BY / BY-SA, лицензии Pexels и Pixabay); автор и лицензия сохраняются в проекте, список для титров — «Файл → Авторы и лицензии»

**Моды и мастерская**
- Свои эффекты, переходы и анимированные элементы на GLSL в файлах `.vrmod` — см. [MODS.md](MODS.md); встроенный каталог примеров, включая набор трендовых эффектов и переходов (ритм-зум, стробоскоп, RGB-тряска, блеск, whip pan, вращение с размытием…)
- Импорт шейдера с Shadertoy по ссылке или коду как эффект либо элемент, с автором и лицензией оригинала
- Мастерская сообщества (вкладка «Мастерская» и [kadro.studio/workshop](https://kadro.studio/workshop/)): эффекты, переходы, элементы, фильтры, стили титров, LUT, темы и шаблоны проектов устанавливаются одним кликом и публикуются прямо из программы — сервер в [workshop/](workshop/README.md)
- Своя библиотека LUT и свои темы оформления

**Шаблоны проектов**
- Как в CapCut: готовый монтаж с пронумерованными слотами — подставьте свои клипы, а эффекты, переходы, титры и музыкальная раскладка остаются на месте
- Любой проект сохраняется шаблоном («Файл → Шаблоны…»): файлы становятся слотами, моды и LUT едут внутри шаблона, пути к вашим файлам не сохраняются

**Медиа и проекты**
- Своё видео из TikTok по ссылке: один раз скачивается в медиатеку (yt-dlp загружается при первом использовании с официальной страницы и проверяется по контрольной сумме)
- Импорт кнопкой или перетаскиванием; неподдерживаемые Chromium форматы (HEVC, ProRes, AVI, MKV с AC3…) получают прокси, тяжёлые 4K-файлы — облегчённые копии для плавного просмотра; экспорт всегда из оригиналов
- Проекты `.vrproj` открываются двойным щелчком, автосохранение и восстановление после сбоя

**Экспорт**
- MP4 (H.264 / H.265), WebM (VP9), MOV (ProRes), GIF, MP3, WAV
- Аппаратное кодирование NVENC / Quick Sync / AMF, если доступно
- Готовые пресеты (YouTube, TikTok/Reels/Shorts, мессенджеры, ProRes, WebM, GIF, MP3) и свои; свой битрейт видео и звука, любая высота кадра
- Предпросмотр и экспорт рисует один и тот же движок, поэтому результат совпадает с тем, что вы видите

**Интерфейс** — пять тем (графит, полночь, мокко, OLED, светлая), любой цвет акцента, масштаб и скругления, собственный заголовок окна и диалоги, украинский, русский и английский языки, настраиваемые панели. Любую команду можно назначить на любую клавишу (Справка → Горячие клавиши). Пресеты титров, фильтров и экспорта переносятся на другой компьютер файлом `.kadropresets` (Настройки → Моё).

## Запуск

Нужен Node.js 20+.

```bash
npm install
```

Режим разработки (горячая перезагрузка интерфейса, автоперезапуск main-процесса):

```bash
npm run dev
```

Сборка и запуск собранной версии:

```bash
npm run build
```

```bash
npm start
```

Установщик (украинский, русский и английский, оформлен в стиле программы) и portable-версия для Windows (папка `release/`):

```bash
npm run dist
```

Выпуск: к релизу `vX.Y.Z` на GitHub прикладываются `Kadro-Setup-X.Y.Z.exe`, `Kadro-Setup-X.Y.Z.exe.blockmap`, `latest.yml` и `Kadro-X.Y.Z-portable.exe`. По `latest.yml` установленные копии сами скачивают новую версию (electron-updater проверяет её SHA-512) и ставят при перезапуске; portable-версия только сообщает о новом релизе. Проверку при запуске можно выключить в настройках.

Название и цвета заголовка окна задаются в `src/shared/brand.ts`, имя установщика — в `package.json` (`productName`, `build`). Иконка: `build/icon.png`, из неё `npm run icon` собирает `build/icon.ico`; картинки установщика рисуются из `build/installer-art.html` командой `npm run art`.

FFmpeg и FFprobe ставятся автоматически через пакеты `ffmpeg-static` и `ffprobe-static`. Чтобы использовать свои сборки, задайте переменные окружения `VR_FFMPEG` и `VR_FFPROBE`.

## Архитектура

```
src/
  shared/                контракт IPC (api.ts) и название продукта (brand.ts)
  main/                  процесс Electron (Node.js)
    index.ts             окно, диалоги, IPC, рабочие процессы
    protocol.ts          media:// — отдача локальных файлов с поддержкой Range и CORS
    media.ts             ffprobe, миниатюры, волновые формы, прокси, стабилизация, шумоподавление
    render.ts            экспорт: декодеры кадров и кодировщик FFmpeg, микширование звука
    mods.ts              установка и каталог модов
  worker/                utility-процессы декодирования и кодирования (кадры идут мимо main)
  preload/index.ts       безопасный мост window.api (contextIsolation + sandbox)
  renderer/              интерфейс (React)
    core/                модель проекта и чистая логика: правки, ключевые кадры, сцена во времени
    engine/              WebGL2-композитор, предпросмотр, экспорт, шейдерные эффекты, скопы
    ai/                  Whisper и MODNet в Web Worker (WebGPU, иначе WASM)
    store/               состояние (zustand + immer), команды, импорт, инструменты улучшения
    components/          панели: медиатека, просмотр, инспектор, таймлайн, диалоги
```

Ключевая идея: `core/scene.ts` по проекту и моменту времени вычисляет список слоёв со всеми трансформациями, анимациями и переходами. Предпросмотр берёт кадры из элементов `<video>`, экспорт — из FFmpeg, но оба передают слои в один и тот же `Compositor`. Собранные кадры экспорта уходят в FFmpeg через stdin, а звук микшируется фильтрами FFmpeg по тому же плану, что и в предпросмотре.

## Проверка

```bash
npm run typecheck
```

Сквозной smoke-тест запускает собранное приложение, импортирует медиа, монтирует, воспроизводит, экспортирует и переоткрывает проект. Тестовые файлы можно сгенерировать самим FFmpeg (`node_modules/ffmpeg-static/ffmpeg`):

```bash
ffmpeg -f lavfi -i testsrc2=size=1280x720:rate=30:duration=6 -f lavfi -i sine=frequency=440:duration=6 -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest test-media/clipA.mp4
ffmpeg -f lavfi -i mandelbrot=size=1920x1080:rate=30 -f lavfi -i sine=frequency=660:duration=5 -t 5 -c:v libx264 -pix_fmt yuv420p -c:a aac test-media/clipB.mp4
ffmpeg -f lavfi -i "color=c=0x00ff00:size=1280x720:rate=30:duration=4,drawbox=x=440:y=160:w=400:h=400:color=red:t=fill" -c:v libx264 -pix_fmt yuv420p test-media/green.mp4
ffmpeg -f lavfi -i sine=frequency=220:duration=8 -c:a libmp3lame test-media/tone.mp3
ffmpeg -f lavfi -i testsrc=size=800x600:rate=1 -frames:v 1 test-media/still.png
ffmpeg -f lavfi -i smptehdbars=size=1280x720:rate=25:duration=3 -f lavfi -i sine=frequency=330:duration=3 -c:v libx265 -pix_fmt yuv420p -c:a ac3 test-media/hevc.mkv
```

```bash
npm run build && node scripts/smoke.mjs test-media smoke-out
```
