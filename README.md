# Videoredact

Бесплатный нелинейный видеоредактор с открытым исходным кодом — в духе Movavi Video, Filmora, CapCut и Adobe Premiere Pro, но написанный с нуля, без заимствования их кода.

Electron + React + TypeScript, собственный WebGL2-композитор, FFmpeg для декодирования и кодирования.

## Возможности

**Монтаж**
- Многодорожечный таймлайн: видео-, аудиодорожки, добавление/удаление/переименование, скрыть / без звука / заблокировать
- Перетаскивание клипов между дорожками, обрезка краёв, привязка (к краям клипов, курсору, маркерам)
- Лезвие, разрезание по курсору, удаление со сдвигом (ripple), устранение пробелов
- Копировать / вырезать / вставить / дублировать, отмена и повтор (200 шагов)
- Маркеры, масштаб таймлайна (Ctrl+колесо), миниатюры кадров и волновые формы на клипах
- Скорость клипа 0.1×–16× (звук без изменения высоты тона), отделение аудио от видео

**Изображение**
- Трансформация: позиция, масштаб, поворот, прозрачность, отражение, обрезка — прямо мышью в окне просмотра
- Анимация по ключевым кадрам (позиция, масштаб, поворот, прозрачность) с плавными кривыми
- Цветокоррекция: экспозиция, яркость, контраст, насыщенность, температура, оттенок, тон, света, тени, виньетка, размытие, резкость
- 15 фильтров-«лутов» (Кино, Винтаж, Нуар, Сепия, Неон…) с регулировкой силы
- Хромакей (зелёный/синий фон) с подавлением ореола и пипеткой
- Режимы наложения: обычный, сложение, умножение, экран
- 22 перехода: растворение, через чёрный/белый, шторки, сдвиги, выталкивание, зум, круг, часы, размытие, вращение
- Анимации появления/исчезновения: проявление, выезды, зум, пружина, вращение, размытие, падение, печатная машинка

**Текст и элементы**
- Титры с пресетами (заголовок, субтитры, нижняя плашка, неон, контур, цитата…), шрифт, обводка, тень, подложка
- Цветные плашки-фоны

**Звук**
- Громкость до 200 %, нарастание/затухание, микширование всех дорожек

**Медиа и проекты**
- Импорт видео, аудио и изображений (кнопкой или перетаскиванием файлов в окно)
- Форматы, которые Chromium не умеет проигрывать (HEVC, ProRes, AVI, MKV с AC3…), автоматически перекодируются в прокси для просмотра; экспорт всегда идёт из оригинала
- Проекты `.vrproj` (JSON), поиск потерянных файлов

**Экспорт**
- MP4 (H.264 / H.265), WebM (VP9), MOV (ProRes), GIF, MP3, WAV
- Выбор разрешения, частоты кадров и качества; сохранение текущего кадра в PNG
- Предпросмотр и экспорт рисуются одним и тем же движком, поэтому результат совпадает с тем, что вы видите, с точностью до кадра

**Интерфейс** — тёмная тема, русский и английский языки, настраиваемые размеры панелей, горячие клавиши (Справка → Горячие клавиши).

## Запуск

Нужен Node.js 20+.

```bash
npm install
```

Режим разработки (горячая перезагрузка интерфейса, автоперезапуск main-процесса):

```bash
npm run dev
```

Сборка и запуск собранной версии:

```bash
npm run build
```

```bash
npm start
```

Установщик для Windows (папка `release/`):

```bash
npm run dist
```

FFmpeg и FFprobe ставятся автоматически через пакеты `ffmpeg-static` и `ffprobe-static`. Чтобы использовать свои сборки, задайте переменные окружения `VR_FFMPEG` и `VR_FFPROBE`.

## Архитектура

```
src/
  shared/api.ts          контракт IPC между процессами
  main/                  процесс Electron (Node.js)
    index.ts             окно, диалоги, IPC
    protocol.ts          media:// — отдача локальных файлов с поддержкой Range и CORS
    media.ts             ffprobe, миниатюры, ленты кадров, волновые формы, прокси (с кэшем)
    render.ts            экспорт: декодеры кадров и кодировщик FFmpeg, микширование звука
  preload/index.ts       безопасный мост window.api (contextIsolation + sandbox)
  renderer/              интерфейс (React)
    core/                модель проекта и чистая логика: правки, ключевые кадры,
                         эффекты, переходы, разрешение сцены во времени
    engine/
      gl.ts              WebGL2-композитор: трансформации, цвет, размытие, хромакей, маски
      player.ts          предпросмотр: синхронизация <video>, Web Audio, отрисовка
      exporter.ts        покадровый рендер для экспорта
      text.ts            растеризация титров
    store/               состояние (zustand + immer), команды, импорт медиа
    components/          панели: медиатека, просмотр, инспектор, таймлайн, диалоги
```

Ключевая идея: `core/scene.ts` по проекту и моменту времени вычисляет список слоёв со всеми трансформациями, анимациями и переходами. Предпросмотр берёт кадры из элементов `<video>`, экспорт — из FFmpeg, но оба передают слои в один и тот же `Compositor`. Собранные кадры экспорта уходят в FFmpeg через stdin, а звук микшируется фильтрами FFmpeg по тому же плану, что и в предпросмотре.

## Проверка

```bash
npm run typecheck
```

Сквозной smoke-тест запускает собранное приложение, импортирует медиа, монтирует, воспроизводит, экспортирует и переоткрывает проект. Тестовые файлы можно сгенерировать самим FFmpeg (`node_modules/ffmpeg-static/ffmpeg`):

```bash
ffmpeg -f lavfi -i testsrc2=size=1280x720:rate=30:duration=6 -f lavfi -i sine=frequency=440:duration=6 -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest test-media/clipA.mp4
ffmpeg -f lavfi -i mandelbrot=size=1920x1080:rate=30 -f lavfi -i sine=frequency=660:duration=5 -t 5 -c:v libx264 -pix_fmt yuv420p -c:a aac test-media/clipB.mp4
ffmpeg -f lavfi -i "color=c=0x00ff00:size=1280x720:rate=30:duration=4,drawbox=x=440:y=160:w=400:h=400:color=red:t=fill" -c:v libx264 -pix_fmt yuv420p test-media/green.mp4
ffmpeg -f lavfi -i sine=frequency=220:duration=8 -c:a libmp3lame test-media/tone.mp3
ffmpeg -f lavfi -i testsrc=size=800x600:rate=1 -frames:v 1 test-media/still.png
ffmpeg -f lavfi -i smptehdbars=size=1280x720:rate=25:duration=3 -f lavfi -i sine=frequency=330:duration=3 -c:v libx265 -pix_fmt yuv420p -c:a ac3 test-media/hevc.mkv
```

```bash
npm run build && node scripts/smoke.mjs test-media smoke-out
```
