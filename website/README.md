# Сайт Kadro

Статическая страница без сборки: `index.html`, `styles.css`, `main.js`, `config.js` и папка `assets/`. Есть украинская, русская и английская версии; язык выбирается по браузеру и переключается в шапке.

Страница мастерской — `workshop/` (`index.html` и `workshop.js`): она показывает элементы с сервера мастерской (адрес сервера и признак «открыта» — в `workshop.json`; тот же файл читает программа, так что мастерская открывается или переезжает без нового выпуска; см. [workshop/README.md](../workshop/README.md)) и открывает их в программе ссылками `kadro://`. При локальном просмотре адрес сервера можно подменить: `/workshop/?api=http://127.0.0.1:9400`.

Страница Kadro Animate — `animate/` (`index.html` и `animate.js`, те же стили и выбор языка). Веб-версия редактора лежит в `animate/app/`: это готовая сборка (`npm run build:site` в проекте Kadro Animate, содержимое `dist-site/` копируется сюда целиком). Установщик для Windows — файл `Kadro-Animate-Setup-<версия>.exe` в отдельном релизе `animate-v<версия>` этого репозитория. Такой релиз публикуется с `--latest=false`, иначе проверка обновлений Kadro и ссылка «последняя версия» начнут смотреть на него. Версия и тег — в разделе `animate` файла `config.js`. Скриншоты страницы лежат по языкам (`assets/animate-screenshot-<язык>.webp`, `assets/animate-assistant-<язык>.webp`), а кнопки «Открыть» ведут в `app/?lang=<язык>`, так что веб-версия открывается на языке сайта.

Статистика скачиваний — `stats/` (`index.html` и `stats.js`, только для автора: в меню её нет, поисковикам она закрыта). GitHub хранит лишь общий счётчик по каждому файлу релиза, поэтому `.github/workflows/download-stats.yml` каждый час (в :07, или вручную из вкладки Actions) сверяет счётчики скриптом `scripts/download-stats.mjs` и, если что-то изменилось, добавляет снимок в `downloads.json` ветки `stats` (с временем предыдущей проверки, так что скачивание известно с точностью до часа). Страница берёт историю с raw.githubusercontent.com и показывает скачивания по дням, по часам суток, журнал (когда, какая версия, установщик или portable), проверки обновлений (скачивания `latest.yml`) и таблицу по версиям; скачивания после последнего снимка — по текущим счётчикам. Проверить на своих данных: `/stats/?data=<адрес json>`.

Настройки — в `config.js`. Достаточно указать `repo` (`аккаунт/имя` на GitHub): ссылки на установщик, portable-версию, исходный код, релизы и сообщения об ошибках строятся из него и номера `version`. Донаты — список `donate`; пустая ссылка показывается как «скоро».

Сайт публикуется на GitHub Pages workflow-файлом `.github/workflows/pages.yml` при каждом изменении папки `website/` в ветке `main`.

Локальный просмотр:

```bash
python -m http.server 5190 --directory website
```
