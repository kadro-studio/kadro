# Сайт Kadro

Статическая страница без сборки: `index.html`, `styles.css`, `main.js`, `config.js` и папка `assets/`. Есть украинская, русская и английская версии; язык выбирается по браузеру и переключается в шапке.

Страница мастерской — `workshop/` (`index.html` и `workshop.js`): она показывает элементы с сервера мастерской (адрес сервера и признак «открыта» — в `workshop.json`; тот же файл читает программа, так что мастерская открывается или переезжает без нового выпуска; см. [workshop/README.md](../workshop/README.md)) и открывает их в программе ссылками `kadro://`. При локальном просмотре адрес сервера можно подменить: `/workshop/?api=http://127.0.0.1:9400`.

Страница Kadro Animate — `animate/` (`index.html` и `animate.js`, те же стили и выбор языка). Веб-версия редактора лежит в `animate/app/`: это готовая сборка (`npm run build:site` в проекте Kadro Animate, содержимое `dist-site/` копируется сюда целиком). Установщик для Windows — файл `Kadro-Animate-Setup-<версия>.exe` в отдельном релизе `animate-v<версия>` этого репозитория. Такой релиз публикуется с `--latest=false`, иначе проверка обновлений Kadro и ссылка «последняя версия» начнут смотреть на него. Версия и тег — в разделе `animate` файла `config.js`.

Настройки — в `config.js`. Достаточно указать `repo` (`аккаунт/имя` на GitHub): ссылки на установщик, portable-версию, исходный код, релизы и сообщения об ошибках строятся из него и номера `version`. Донаты — список `donate`; пустая ссылка показывается как «скоро».

Сайт публикуется на GitHub Pages workflow-файлом `.github/workflows/pages.yml` при каждом изменении папки `website/` в ветке `main`.

Локальный просмотр:

```bash
python -m http.server 5190 --directory website
```
