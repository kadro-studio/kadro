# Сайт Kadro

Статическая страница без сборки: `index.html`, `styles.css`, `main.js`, `config.js` и папка `assets/`. Есть русская и английская версии, язык выбирается по браузеру и переключается кнопкой.

Перед публикацией заполните `config.js`: ссылки на установщик и portable-версию (например, на GitHub Releases), на исходный код и на страницы донатов. Пустая ссылка показывается как «скоро».

Локальный просмотр:

```bash
python -m http.server 5190 --directory website
```

Подойдёт любой статический хостинг: GitHub Pages, Cloudflare Pages, Netlify. Содержимое папки `website/` загружается как есть.
