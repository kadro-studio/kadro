# Моды Kadro

Мод добавляет в редактор новый **эффект**, **переход** или **анимированный элемент** (оверлей, фон). Это небольшой JSON-файл с расширением `.vrmod`, внутри которого лежит GLSL-шейдер.

Шейдер выполняется только на видеокарте внутри WebGL. У мода нет доступа к файлам, сети или системе, поэтому его безопасно установить даже из незнакомого источника. В худшем случае неудачный шейдер нарисует неправильную картинку или не скомпилируется — тогда редактор покажет ошибку и пропустит такой мод.

## Установка

- Вкладка **Моды** → «Установить мод…» или выбор из каталога.
- Или перетащите `.vrmod`-файл в окно программы.
- Установленные моды лежат в папке, которую открывает кнопка «Папка модов».

Проект, в котором использован мод, хранит копию его шейдера. Поэтому такой проект откроется у другого человека, даже если у того мод не установлен.

## Формат файла

```json
{
  "format": 1,
  "id": "author.my-effect",
  "kind": "effect",
  "name": "My effect",
  "nameRu": "Мой эффект",
  "author": "Имя автора",
  "version": "1.0.0",
  "description": "Что делает эффект",
  "params": [
    { "id": "amount", "name": "Amount", "nameRu": "Сила", "min": 0, "max": 1, "default": 0.5, "step": 0.01 }
  ],
  "glsl": "vec4 effect(vec2 uv) { vec4 c = src(uv); c.rgb *= amount; return c; }"
}
```

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Уникальный идентификатор: латиница, цифры, `.`, `_`, `-`. Удобный формат — `автор.название`. |
| `kind` | да | `"effect"`, `"transition"` или `"generator"`. |
| `name`, `nameRu`, `nameUk` | `name` | Название в интерфейсе; `nameRu` и `nameUk` показываются при русском и украинском языке (у параметров так же). |
| `params` | нет | До 8 числовых параметров. Каждый превращается в переменную шейдера с именем `id`, а в инспекторе для него появляется ползунок. |
| `glsl` | да | Код шейдера (GLSL ES 3.00, без `#version`). |
| `author`, `version`, `description` | нет | Показываются в менеджере модов; `descriptionRu` и `descriptionUk` — описание на русском и украинском. |

## Эффект

Нужно определить функцию `vec4 effect(vec2 uv)`, которая возвращает цвет пикселя.

| Доступно | Что это |
|---|---|
| `src(uv)` | Цвет исходного кадра клипа в точке `uv` (прямая альфа). |
| `uv` | Координаты 0…1, `(0,0)` — левый нижний угол. |
| `u_size` | Размер исходника в пикселях (`vec2`). |
| `u_time` | Секунды от начала клипа — пригодится для анимации. |
| `rand(vec2)`, `luma(vec3)`, `PI` | Псевдослучайное число 0…1, яркость, π. |

Эффекты на клипе применяются по очереди, сверху вниз: следующий получает результат предыдущего.

## Переход

Нужно определить функцию `vec4 transition(vec2 uv)`. Она смешивает уходящий клип с приходящим.

| Доступно | Что это |
|---|---|
| `fromColor(uv)` | Кадр уходящего клипа (уже со всеми его трансформациями и эффектами). |
| `toColor(uv)` | Кадр приходящего клипа. |
| `progress` | 0 → только уходящий, 1 → только приходящий. |
| `ratio` | Ширина кадра, делённая на высоту. |

Цвета передаются с **предумноженной альфой**, поэтому линейное смешивание (`mix`) работает корректно и на прозрачных слоях. Для совместимости также доступны имена `getFromColor` и `getToColor`.

## Анимированный элемент

Нужно определить функцию `vec4 generate(vec2 uv)`: она рисует кадр с нуля, без исходного видео. Такие элементы появляются во вкладке **Элементы** и ложатся на таймлайн отдельным клипом.

| Доступно | Что это |
|---|---|
| `uv` | Координаты 0…1, `(0,0)` — левый нижний угол. |
| `time` | Секунды от начала клипа. |
| `ratio` | Ширина кадра, делённая на высоту. |
| `u_size` | Размер кадра в пикселях. |
| `colorA`, `colorB` | Два цвета элемента (`vec3`), пользователь меняет их в инспекторе. |

Возвращается цвет с **прямой** альфой. Дополнительные поля: `"blend"` — режим наложения по умолчанию (`"screen"` для свечения, `"overlay"` для зерна), `"colors"` — два цвета по умолчанию, `"category"` — `"overlay"` или `"background"`.

```json
{
  "format": 1,
  "id": "author.glow-dots",
  "kind": "generator",
  "name": "Glow dots",
  "blend": "screen",
  "colors": ["#ff3b4f", "#ffd23f"],
  "category": "overlay",
  "params": [{ "id": "speed", "name": "Speed", "min": 0, "max": 3, "default": 1 }],
  "glsl": "vec4 generate(vec2 uv) { vec2 p = fract(uv * vec2(ratio, 1.0) * 6.0) - 0.5; float d = length(p); float pulse = 0.5 + 0.5 * sin(time * speed * 3.0 + uv.x * 10.0); return vec4(mix(colorA, colorB, uv.y) * smoothstep(0.2, 0.0, d) * pulse, 1.0); }"
}
```

## Советы

- Проверяйте крайние значения: при `progress = 0` переход должен показывать только `fromColor`, при `progress = 1` — только `toColor`.
- Не используйте зарезервированные имена GLSL (`half`, `sample`, `input`, `output`, `filter`) как `id` параметров.
- Ошибки компиляции видны во вкладке «Моды» — номера строк считаются от начала вашего `glsl`.
- Примеры лежат в папке [`mods/`](mods) репозитория и в каталоге внутри программы.
