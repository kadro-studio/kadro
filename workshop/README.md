# Мастерская Kadro

Плагин WordPress `kadro-workshop` — сервер мастерской: пользователи публикуют из программы эффекты, переходы, элементы, фильтры, стили титров, LUT, темы и шаблоны проектов, а остальные устанавливают их одним кликом. Программа и страница [kadro.studio/workshop](https://kadro.studio/workshop/) обращаются к нему через REST API `kadro/v1`.

## Что внутри

- Тип записей «Элементы Kadro» (`kadro_item`) и метки (`kadro_tag`). Файлы хранятся в `wp-content/uploads/kadro-workshop` с запретом прямого доступа и отдаются только через API.
- Регистрация для публикации: страница `/?kadro=join` (кнопка «Создать аккаунт» в программе и на kadro.studio/workshop) — имя, e-mail, пароль и согласие с правилами, защита от ботов (скрытое поле, не больше 5 регистраций в час с адреса и обычные фильтры WordPress `registration_errors`). Из программы после регистрации сразу открывается разрешение для Kadro, и программа входит сама. Публиковать можно после подтверждения e-mail по ссылке из письма (письмо можно отправить ещё раз из программы); аккаунты, созданные иначе (администратор, приглашённые), считаются подтверждёнными.
- Модерация: публикации обычных пользователей попадают в «На утверждении», редакторы и администраторы публикуют сразу. Модераторы проверяют прямо в программе (вкладки «На проверке» и «Жалобы» в «Мастерской»): «Одобрить» или «Отклонить» с причиной — элемент возвращается автору черновиком, причину он видит в программе и получает письмом. Новая версия снова идёт на проверку. Администратор получает письмо о каждой новой публикации на проверку и о первой жалобе на элемент. Счётчик ожидающих — и рядом с пунктом меню в админке, колонка «Жалобы» — в списке элементов.
- Жалобы: вошедшие пользователи жалуются на опубликованное с причиной (одна жалоба от человека); модератор оставляет элемент или снимает его с публикации.
- Доверенные авторы: после N одобренных публикаций (по умолчанию 3, «Элементы Kadro → Настройки», 0 — проверять всегда) автор публикует без проверки.
- Проверка каждого файла по виду: моды (те же правила, что в программе), LUT (размер и число строк), фильтры, стили, темы и шаблоны. В шаблоне не может быть путей к файлам: все медиа — пустые слоты.
- Лайки, счётчик скачиваний (раз в сутки с одного адреса), лимит публикаций в день.
- Страница элемента на сайте с кнопками «Открыть в Kadro» (`kadro://workshop/item/ID`), «Скачать» и «Нравится».

## Установка

1. Соберите архив: `npm run workshop:zip` → `release/kadro-workshop.zip`.
2. В WordPress: «Плагины → Добавить новый → Загрузить плагин», выберите архив и активируйте.
3. «Настройки → Общие»: включите «Любой может зарегистрироваться» с ролью «Подписчик».
4. «Настройки → Постоянные ссылки»: любой вариант, кроме «Простые» (нужно для REST API).
5. Сайт должен работать по HTTPS: пароли приложений WordPress без него отключены.
6. «Элементы Kadro → Настройки»: публикация без проверки (по умолчанию выключена) и лимит публикаций в день.

Программа ищет мастерскую по адресу `https://workshop.kadro.studio` (`WORKSHOP_URL` в `src/shared/brand.ts`; для проверки на своём сервере — переменная окружения `KADRO_WORKSHOP_URL`). Сайт и программа берут адрес мастерской и признак `open` из `website/workshop.json` (программа — с kadro.studio, кэш на 30 минут). Чтобы открыть мастерскую или перенести сервер, достаточно поменять этот файл.

## Вход из программы

Пользователь нажимает «Войти» в программе: открывается страница WordPress «Авторизовать приложение», после подтверждения сайт возвращает в Kadro ссылку `kadro://auth` с паролем приложения. Пароль хранится зашифрованным (Electron safeStorage) и в любой момент отзывается в профиле WordPress. Основной пароль пользователя программа не видит.

## API

| Метод | Путь | Доступ |
| --- | --- | --- |
| GET | `/items?kind=&search=&sort=popular\|new\|liked&page=&per_page=&mine=&review=pending\|reported` | все (`mine` — после входа, `review` — модераторы) |
| POST | `/items` (multipart: `kind`, `title`, `description`, `tags`, `version`, `license`, `file`, `preview`, `update`) | после входа |
| GET / DELETE | `/items/{id}` | все / автор и редакторы |
| GET | `/items/{id}/file` | все |
| POST | `/items/{id}/like` | после входа |
| GET | `/me` (имя, логин, `confirmed`, `moderator`; модераторам — `pending`, `reported`) | после входа |
| POST | `/me/confirm` — отправить письмо с подтверждением ещё раз (не больше 3 в час) | после входа |
| POST | `/items/{id}/review` (`action`: `approve`, `reject` с `reason`, `dismiss` — снять жалобы) | модераторы |
| POST | `/items/{id}/report` (`reason`) | после входа, не на своё |

Ошибки, которые программа объясняет на языке пользователя: `kw_unconfirmed` (403, e-mail не подтверждён) и `kw_resend_limit` (429). Элемент в ответах дополнительно содержит `own`, `rejected` (причина — автору и модераторам), `reports` и `reportReasons` (модераторам).
