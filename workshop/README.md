# Мастерская Kadro

Плагин WordPress `kadro-workshop` — сервер мастерской: пользователи публикуют из программы эффекты, переходы, элементы, фильтры, стили титров, LUT, темы и шаблоны проектов, а остальные устанавливают их одним кликом. Программа и страница [kadro.studio/workshop](https://kadro.studio/workshop/) обращаются к нему через REST API `kadro/v1`.

## Что внутри

- Тип записей «Элементы Kadro» (`kadro_item`) и метки (`kadro_tag`). Файлы хранятся в `wp-content/uploads/kadro-workshop` с запретом прямого доступа и отдаются только через API.
- Модерация: публикации обычных пользователей попадают в «На утверждении», редакторы и администраторы публикуют сразу. Счётчик ожидающих — рядом с пунктом меню.
- Проверка каждого файла по виду: моды (те же правила, что в программе), LUT (размер и число строк), фильтры, стили, темы и шаблоны. В шаблоне не может быть путей к файлам: все медиа — пустые слоты.
- Лайки, счётчик скачиваний (раз в сутки с одного адреса), лимит публикаций в день.
- Страница элемента на сайте с кнопками «Открыть в Kadro» (`kadro://workshop/item/ID`), «Скачать» и «Нравится».

## Установка

1. Соберите архив: `npm run workshop:zip` → `release/kadro-workshop.zip`.
2. В WordPress: «Плагины → Добавить новый → Загрузить плагин», выберите архив и активируйте.
3. «Настройки → Общие»: включите «Любой может зарегистрироваться» с ролью «Подписчик».
4. «Настройки → Постоянные ссылки»: любой вариант, кроме «Простые» (нужно для REST API).
5. Сайт должен работать по HTTPS: пароли приложений WordPress без него отключены.
6. «Элементы Kadro → Настройки»: публикация без проверки (по умолчанию выключена) и лимит публикаций в день.

Программа ищет мастерскую по адресу `https://workshop.kadro.studio` (`WORKSHOP_URL` в `src/shared/brand.ts`; для проверки на своём сервере — переменная окружения `KADRO_WORKSHOP_URL`). Страница мастерской на сайте берёт адрес из `workshop` в `website/config.js`.

## Вход из программы

Пользователь нажимает «Войти» в программе: открывается страница WordPress «Авторизовать приложение», после подтверждения сайт возвращает в Kadro ссылку `kadro://auth` с паролем приложения. Пароль хранится зашифрованным (Electron safeStorage) и в любой момент отзывается в профиле WordPress. Основной пароль пользователя программа не видит.

## API

| Метод | Путь | Доступ |
| --- | --- | --- |
| GET | `/items?kind=&search=&sort=popular\|new\|liked&page=&per_page=&mine=` | все (`mine` — после входа) |
| POST | `/items` (multipart: `kind`, `title`, `description`, `tags`, `version`, `license`, `file`, `preview`, `update`) | после входа |
| GET / DELETE | `/items/{id}` | все / автор и редакторы |
| GET | `/items/{id}/file` | все |
| POST | `/items/{id}/like` | после входа |
| GET | `/me` | после входа |
